What is the Knapsack Problem?
Imagine you are loading a truck with cargo items. Each item has a weight and a value. The truck can only carry up to a maximum weight. Your goal is to choose which items to load so that the total value is maximized without exceeding the weight limit. This is called the 0/1 Knapsack Problem — each item is either fully loaded (1) or not loaded (0).
Why Dynamic Programming?
A brute-force approach would try all 2ⁿ combinations (for n items) — that's exponential! DP breaks the problem into smaller sub-problems and stores their results to avoid recomputation, making it run in O(n × W) time, where W is the weight capacity.
Step-by-Step: How It Works
Step 1 — Create the DP table
Build a 2D table dp[i][w] where i = item index and w = weight capacity. dp[i][w] stores the maximum value achievable using the first i items with capacity w.
Step 2 — Fill the table
For each item i and capacity w:
If item weight > w: dp[i][w] = dp[i-1][w] (skip the item)
Otherwise: dp[i][w] = max(dp[i-1][w], value[i] + dp[i-1][w - weight[i]])
Step 3 — Traceback selected items
Start from dp[n][W] and trace back. If dp[i][w] ≠ dp[i-1][w], item i was selected.
The JavaScript Code
function knapsack(items, maxWeight) {
  const n = items.length;

  // Create DP table filled with 0s
  const dp = [];
  for (let i = 0; i <= n; i++) {
    dp[i] = new Array(maxWeight + 1).fill(0);
  }

  // Fill the table
  for (let i = 1; i <= n; i++) {
    for (let w = 0; w <= maxWeight; w++) {
      if (items[i-1].weight > w) {
        dp[i][w] = dp[i-1][w]; // Can't include this item
      } else {
        dp[i][w] = Math.max(
          dp[i-1][w],                              // Exclude item
          items[i-1].value + dp[i-1][w - items[i-1].weight] // Include item
        );
      }
    }
  }

  // Traceback to find selected items
  const selected = [];
  let w = maxWeight;
  for (let i = n; i > 0; i--) {
    if (dp[i][w] !== dp[i-1][w]) {
      selected.push(i - 1);   // Item was included
      w -= items[i-1].weight;
    }
  }

  return { maxValue: dp[n][maxWeight], selected, dp };
}
